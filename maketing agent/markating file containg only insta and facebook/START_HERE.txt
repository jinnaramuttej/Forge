───────────────────────────────────────────────────────────────────────────────
🚨 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Problem: Server won't start
Fix: Make sure port 5000 is free. Run: netstat -ano | findstr :5000

Problem: Instagram error
Fix: Session ID may be expired. Get new one and update .env

Problem: Facebook login fails
Fix: Check email/password in .env. Verify credentials work manually.

Problem: "Cannot reach server"
Fix: Is the server still running? Check terminal. Run: python instagram_api.py
