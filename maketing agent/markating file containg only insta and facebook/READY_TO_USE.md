## 🚨 Troubleshooting

### Issue: Server won't start
**Solution:** Make sure port 5000 is free
```bash
# Check: netstat -ano | findstr :5000
# Kill: taskkill /PID <PID> /F
```

### Issue: Instagram shows error
**Solution:** Session ID may be expired
- Get new session ID from Instagram
- Update `.env`
- Restart server

### Issue: Facebook login fails
**Solution:** Check credentials
- Verify email/password in `.env`
- Try logging in manually first
- Make sure 2FA is disabled

### Issue: Nothing happens when posting
**Check:**
1. Server is running (`python instagram_api.py`)
2. At least one platform is checked
3. Image is selected
4. Caption is added (optional but recommended)
