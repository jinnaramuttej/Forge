# 📱 Facebook Token Setup - Just Like Instagram!

## ✅ Much Easier Than Browser!

Instead of browser automation, use **Facebook Graph API Token** - just like Instagram Session ID!

---

## 🚀 Super Quick Setup (5 minutes)

### Step 1: Get Your Token
Go to: **https://developers.facebook.com/tools/accesstoken**

You'll see your token at the top. Copy it (looks like: `EAA1234567890...`)

### Step 2: Get Your Page ID
If you have a Facebook page:
1. Go to your page
2. Look for page ID (or use: https://findmyfbid.com)
3. Copy it (looks like: `123456789`)

### Step 3: Add to .env
Open `.env` and add:
```env
FACEBOOK_ACCESS_TOKEN=EAA1234567890...
FACEBOOK_PAGE_ID=123456789
```

### Step 4: Done!
Run: `python instagram_api.py`
